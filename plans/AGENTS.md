This directory has all the plans for features & architecture.

When writing or updating plans, please refer to the documentation on the
subjects that the plan touches upon.

Main documents that should be kept in mind:

- `docs/architecture/monorepo.md`: a detailed description of the architecture
  & structure of this monorepo. Before making structural changes, adding
  dependencies, creating a new service, or moving code between packages,
  contributors should read this document.
- `docs/architecture/database-crate.md`: a detailed description of the
  architecture & structure of the repository databse crate. Please refer to
  this document whenever you need to doing anything related to the database.
