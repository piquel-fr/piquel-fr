# Contributing

Thanks for helping with SourceOrigin. The contributor guide covers everything you
need:

- [Getting started](docs/dev/getting-started.md): tools, building and previews.
- [Contributing](docs/dev/contributing.md): how a change gets to `main`.
- [Testing](docs/dev/testing.md): what to run before a pull request.
- [Changing the documentation](docs/dev/documentation.md).

Questions are welcome at [contact@sourceorigin.dev](mailto:contact@sourceorigin.dev). Report
security vulnerabilities privately, as [SECURITY.md](SECURITY.md) describes.
