# piquel-fr

This repository conatains everything under the piquel.fr domain.
For now, that is an authentication service, its utility crates and SDKs for the
authentication service.

This is still very early development. Breaking changes are expected. There are
no real users yet so breaking things doesn't matter.

## Guidelines

When adding a feature, make sure all our surfaces get the feature as
appropriate. This include the developer console, the user settings, the
admin panel and the SDKs. All surfaces should support all features. Don't let
anything be left behind.
